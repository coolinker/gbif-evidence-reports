# Contributing a report

Before opening an issue with GBIF, prepare a report containing:

1. A one-sentence description of the observed behaviour.
2. Clickable example URLs or complete API calls.
3. The exact action performed.
4. Expected and observed results.
5. Stable identifiers such as dataset, taxon, occurrence, or download keys.
6. The retrieval date and API version.
7. One primary question or requested action.

For taxonomy-related reports, distinguish:

- source data;
- GBIF's interpreted occurrence data;
- the taxonomy used by the query;
- external taxonomic authorities.

Do not claim that a taxonomy is biologically wrong unless an appropriate
authority is cited. A reproducible query-behaviour report does not require a
taxonomic judgment.

Large benchmarks, scripts, and secondary proposals belong in this repository,
not in the initial external issue body.
